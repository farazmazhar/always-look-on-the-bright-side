# Course Note-Taking Conventions

## Structure
- Section folders: `sNN-topic-name` (e.g., `s02-gist-of-langchain`)
- Lecture files: `lecture-NN-lecture-name.md` (e.g., `lecture-06-what-is-langchain.md`)
- NN uses zero-padded two-digit numbers

## Note Creation
- When user says "section N, lecture M" — create folder and file using the conventions above
- When user says only "lecture M" — assume same section as last created
- s01-introduction exists but has no notes (none needed)
