# Debugging and Tracing Our LangChain Chain

## What We Did

Debugged the summary chain to understand how data flows between components and inspect the objects involved.

## Steps

### 1. Set Up the Debugger
- Set a breakpoint in `main.py` right after `chain.invoke()`.
- Ran the script in debug mode → execution paused at the breakpoint.

### 2. Inspect the Response Object
The `response` variable is **not a simple string** — it's an `AIMessage` object (LangChain wrapper for LLM output).

### 3. Analyzing the AIMessage Object
- **`.content`** — main text generated by the LLM.
- **`.response_metadata`** — diagnostic info:
  - Exact model name (e.g., `gpt-5-2025-08-07`)
  - Token usage (input tokens, completion tokens, total tokens)
  - `finish_reason` (e.g., `stop`) — why the model stopped generating

### 4. Conclusion
Metadata is crucial for debugging, monitoring costs, and analyzing LLM call performance. Stepping through with a debugger revealed how `PromptTemplate` and `ChatOpenAI` work together within the chain and what structured data passes between them.
