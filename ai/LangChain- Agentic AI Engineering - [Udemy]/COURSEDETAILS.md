## Summary

Build AI Agents with LangChain and LangGraph — RAG, Tools, MCP and Production-Ready Agentic AI Systems (Python).

## Prerequisites

- Python knowledge
- Git usage
- Virtual environments, environment variables
- No AI/ML knowledge needed (covered in-course)

## What You'll Learn

- Become proficient in LangChain
- End-to-end LangChain-based generative AI agents
- Prompt Engineering Theory: Chain of Thought, ReAct, Few Shot prompting
- Context Engineering
- LangChain open-source codebase navigation
- LLMs theory for software engineers
- LangChain primitives: Chains, Agents, DocumentLoader, TextSplitter, OutputParser, Memory
- RAG, Vectorstores / Vector Databases (Pinecone, FAISS)
- Model Context Protocol (MCP)

- Groq API integration

## Key Tools & Technologies

- **LangChain / LangGraph / LangSmith** — core framework
- **OpenAI** (`gpt-5`, `gpt-4o`) — primary LLM provider
- **Ollama** — local open-weight models (Qwen, Gemma)
- **Tavily** — web search API for AI agents
- **Groq** — high-performance inference API
- **Pinecone / FAISS / Chroma** — vector databases
- **Pydantic** — structured output schemas
- **Python** (`uv` package manager, `python-dotenv`, `black`, `isort`)
- **FastAPI + Docker** — deployment
