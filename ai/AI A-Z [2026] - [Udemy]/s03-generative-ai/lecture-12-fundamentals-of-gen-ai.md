# Lecture 12 — Fundamentals of Generative AI

## Where Gen AI fits in AI

```
Artificial Intelligence
 ├── Machine Learning (elite branch)
 │   └── Deep Learning (elite branch)
 │       └── Generative AI (elite branch, cutting edge)
 │           ├── LLMs (Large Language Models)
 │           ├── Diffusion Models
 │           └── ...
 └── Other branches (rule-based systems, expert systems, etc.)
```

## How it works

1. Feed the model **massive amounts of data** — text, images, audio, video (any modality)
2. Model is **trained** on this data — learns patterns, structures, relationships
3. After training, it can **generate new, never-before-seen data** — not regurgitating, but creating

> In a nutshell: learn from examples → produce original output.

## Use Cases

| Domain | Examples |
|---|---|
| **Text Generation** | Articles, stories, scripts, code, poetry |
| **Image Generation** | Art, design mockups, photorealistic scenes |
| **Audio Generation** | Music, voice synthesis, sound effects |
| **Video Generation** | Short clips, animations, deepfakes |
| **Summarization** | Condense articles, books, meeting notes |
| **Translation** | Language-to-language, code-to-code |
| **Chatbots** | Customer support, personal assistants, tutors |
| **Search** | Semantic search, Q&A over documents |
