Tokio's scheduler is a multi-threaded, work-stealing runtime. Rough mental model:

Each worker thread owns a local run queue (usually LIFO for cache locality).
When idle, a worker steals tasks from other workers' queues (FIFO half) or the global injector.
Tasks are cooperative: they yield at .await points; no preemption of pure CPU loops.
I/O and timers live on separate drivers; readiness wakes tasks back onto queues.

Here's a minimal multi-threaded executor (toy — not production-safe):

rust 
use std::collections::VecDeque;
use std::sync::{Arc, Mutex, Condvar};
use std::thread;

type Job = Box<dyn FnOnce() + Send + 'static>;

struct Executor {
    queue: Mutex<VecDeque<Job>>,
    cv: Condvar,
    shutdown: Mutex<bool>,
}

impl Executor {
    fn new(workers: usize) -> Arc<Self> {
        let ex = Arc::new(Self {
            queue: Mutex::new(VecDeque::new()),
            cv: Condvar::new(),
            shutdown: Mutex::new(false),
        });
        for _ in 0..workers {
            let ex = Arc::clone(&ex);
            thread::spawn(move || loop {
                let job = {
                    let mut q = ex.queue.lock().unwrap();
                    while q.is_empty() && !*ex.shutdown.lock().unwrap() {
                        q = ex.cv.wait(q).unwrap();
                    }
                    if q.is_empty() { break; }
                    q.pop_front()
                };
                if let Some(job) = job { job(); }
            });
        }
        ex
    }

    fn spawn<F: FnOnce() + Send + 'static>(&self, f: F) {
        self.queue.lock().unwrap().push_back(Box::new(f));
        self.cv.notify_one();
    }
}

Classic pattern: local push/pop on one end, steal from the other.

rust 
struct WorkerQueue {
    // conceptually: local LIFO end + steal FIFO end
    deque: Mutex<VecDeque<Job>>,
}

impl WorkerQueue {
    fn push_local(&self, job: Job) {
        self.deque.lock().unwrap().push_back(job); // LIFO with pop_back
    }

    fn pop_local(&self) -> Option<Job> {
        self.deque.lock().unwrap().pop_back()
    }

    /// Other workers call this
    fn steal(&self) -> Option<Job> {
        let mut q = self.deque.lock().unwrap();
        // steal from the opposite end (FIFO)
        q.pop_front()
    }

    fn steal_half(&self) -> Vec<Job> {
        let mut q = self.deque.lock().unwrap();
        let n = (q.len() + 1) / 2;
        q.drain(..n).collect()
    }
}
Local LIFO — hot tasks stay cache-warm.
Steal FIFO / half — older work spreads out; reduces thundering herd on one victim.
Lock-free deques (Chase-Lev style) are what production runtimes actually use.
